## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor-submitted values → server validation | Untrusted form fields cross into server-side input handling. |
| Server action state → public form markup | Error output is reflected to visitors and must not include submitted sensitive values or executable content. |

| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
