## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Payload media records → public image projection | Derivative URLs cross from stored media into anonymous page and social metadata output. |
| Public projection → browser image requests | Only verified responsive derivatives and reviewed alt text may reach the visitor. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information Disclosure | Public image projection and social metadata | high | mitigate | Require the existing verified-media gate, resolve only named responsive derivatives, and test that original/private URLs cannot enter card, gallery or metadata output. |
| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
</threat_model>
