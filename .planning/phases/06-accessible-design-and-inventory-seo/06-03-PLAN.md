<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Payload media relations and files → public image UI/share metadata | Only public reviewed derivatives may be rendered or shared; private masters/documents remain inaccessible. |
| Visitor-submitted form data → validation feedback | Raw values are untrusted and must not become executable markup or be copied into error messages. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information Disclosure | Image projection, gallery and share metadata | high | mitigate | Reuse public Payload reads, the existing verified-media flag and safe same-origin derivative path validation for every size; never use private master or document URLs. |
| T-06-07 | Tampering | Enquiry validation errors and rendered controls | medium | mitigate | Map bounded server validation messages to fixed field keys, preserve React text rendering and verify no visitor value is used as markup or error text. |
| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
</threat_model>
