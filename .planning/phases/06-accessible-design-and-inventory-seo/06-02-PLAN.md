## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Published machine facts and approved photo derivatives → public homepage | Render only data already returned by the public projection. |
| Visitor viewport, keyboard and reduced-motion preferences → presentation | Layout and motion behavior must not hide primary page information or actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Information Disclosure | Homepage image and machine cards | medium | mitigate | Keep image use behind the existing public-media projection and render only its eligible derivative URL; the text fallback remains available when the media gate supplies no image. |
| T-06-05 | Denial of Service | Homepage hero and primary controls | low | mitigate | Keep all content server-rendered and immediately available; motion is disabled unless verified layered media and performance/usability checks exist, with reduced-motion/mobile fallbacks preserved. |
| T-06-10 | Tampering | Shared palette, action and focus styles | medium | mitigate | Use an explicit sRGB/WCAG contrast matrix in `tests/phase6-brand.test.mjs` to reject any used text pair below 4.5:1 or large-text/non-text/focus pair below 3:1, including hover/active and dark-surface focus states. |
| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
</threat_model>
