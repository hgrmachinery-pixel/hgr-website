<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Payload public records → route metadata and JSON-LD | Only published public machine/page facts may enter route metadata and structured data. |
| `SERVER_URL` and `HGR_PUBLIC_INDEXING_ENABLED` → canonical host and robots policy | Environment configuration determines which origin crawlers receive and whether indexing is enabled. |
| Inventory query parameters → canonical and robots metadata | Search, brand, status and page inputs are untrusted URL data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information Disclosure | Machine route metadata and JSON-LD | high | mitigate | Build output only from `getPublicMachines`, `getPublicMachineForSlug` and their public projection; test draft/private fields and records are not represented. |
| T-06-02 | Spoofing | `src/lib/siteMetadata.ts` | medium | mitigate | Parse `SERVER_URL` as a credential-free HTTP(S) origin and keep indexability disabled unless production and explicit opt-in are both present. |
| T-06-03 | Tampering | Machine metadata and JSON-LD | medium | mitigate | Never reflect query values into metadata/schema; serialize visible projection text with HTML-safe JSON-LD encoding and cover unusual characters in tests. |
| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
</threat_model>
