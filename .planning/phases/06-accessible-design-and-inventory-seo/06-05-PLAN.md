<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Published Payload records → sitemap | Public inventory and page facts enter crawler-facing output. |
| `SERVER_URL` and `HGR_PUBLIC_INDEXING_ENABLED` → robots/sitemap policy | Environment configuration selects the canonical origin and whether indexable crawler output is available. |
| Crawler directives → public route discovery | Robots/sitemap guide compliant crawlers but do not authorize access or protect private resources. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-08 | Information Disclosure | `src/app/sitemap.ts` | high | mitigate | Generate sitemap entries only from fixed eligible public routes and the published public inventory query; assert drafts, private fields and private destinations never appear. |
| T-06-09 | Spoofing | `src/app/robots.ts` and `src/app/sitemap.ts` | medium | mitigate | Require a valid credential-free HTTP(S) `SERVER_URL`, production runtime and explicit opt-in before emitting public crawler destinations; test every closed-policy case. |
| T-06-SC | Tampering | Package installation | high | mitigate | No dependency installation is planned; any proposed install must pass the package-legitimacy audit and a blocking human checkpoint for `[ASSUMED]` or `[SUS]` packages. |
</threat_model>
