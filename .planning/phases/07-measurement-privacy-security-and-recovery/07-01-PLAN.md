<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → analytics provider | Event data and campaign parameters leave the site for an external processor. |
| Enquiry form → server action → browser event | Untrusted form fields cross a server validation and email-acceptance boundary. |
| Runtime configuration → client | Only an approved public container identifier and consent result may be exposed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information Disclosure | Analytics event payload | high | mitigate | Field-by-field event allowlist and synthetic PII/serial sentinel assertions. |
| T-07-02 | Spoofing | Accepted enquiry conversion signal | medium | mitigate | Emit success only from the server-returned accepted state, not a caller-controlled event name or click. |
| T-07-03 | Tampering | Runtime tag and consent gate | medium | mitigate | Fail closed on missing/invalid configuration and require the reviewed consent state before loading external scripts. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is planned; if a future approved implementation proposes one, require package legitimacy evidence and a blocking review for any [ASSUMED]/[SUS] package. |
</threat_model>
