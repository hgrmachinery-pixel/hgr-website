<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor browser → enquiry handler | Untrusted form values, spam attempts, forged machine/page fields |
| Public route → Payload page/contact reads | Public content must remain published-only and allow-listed |
| Enquiry handler → email provider | Customer PII crosses to a configured receiver/provider only after validation |
| Legal content editor → public legal routes | Owner-approved wording must be recorded before publication |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | Enquiry action and machine context | medium | mitigate | Resolve machine context server-side from canonical slug; validate typed fields, bounds, and honeypot before send. |
| T-05-02 | Information Disclosure | Form errors, URLs, logs, delivery payload | high | mitigate | Never place PII/free text in URLs or ordinary logs; only send to configured receiver through provider; render generic failure/accepted feedback. |
| T-05-03 | Denial of Service | Public enquiry routes | medium | mitigate | Bound body/field lengths, reject honeypot, keep validation low-friction; use no external rate-limit dependency in this plan. |
| T-05-04 | Information Disclosure | Payload Pages public reads | medium | mitigate | Keep public access published-only and map fixed public route slugs; never accept arbitrary draft lookup. |
| T-05-05 | Repudiation | Legal-page publication state | medium | mitigate | Only the persisted Owner may create, edit, publish, rename or delete legal pages; Owner publication is the explicit approval action, while pages remain unavailable until non-empty content is published. |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | The Owner authorized an SMTP implementation and Nodemailer dependency for Phase 5. Pin the dependency; do not install unrelated packages. |
</threat_model>
