<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff browser/API → role assignments | Untrusted users may forge role keys, permission arrays or assignments. |
| Anonymous request → document record/file/object | A guessed ID or direct object request may target originals, private previews or pending redactions. |
| Admin/REST/GraphQL/Local API → review transitions | Client-supplied workflow fields or version restore may forge review/publication state. |
| Human reviewer → public eligibility | Review can be stale after bytes, crop, metadata or machine serial policy changes. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Elevation of privilege | Roles, User assignments and permission resolver | high | mitigate | Resolve persisted role permissions per request from authenticated user ID; protect role editing and assignments. |
| T-03-04 | Information disclosure | MachineDocuments APIs and object delivery | high | mitigate | Deny anonymous API/file/object/optimizer paths for originals, previews and pending revisions; keep GCS private. |
| T-03-05 | Tampering | Document hooks and Admin/API updates | high | mitigate | Check effective persisted-plus-incoming state and use server-owned narrow markers; reject client workflow/audit fields. |
| T-03-08 | Repudiation / tampering | Photo and document review state | high | mitigate | Bind reviewer evidence to revision/digest and invalidate on replacement, policy change or re-redaction; preserve D-10 checklist. |
