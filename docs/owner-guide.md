# HGR Website Owner Guide

This guide covers the website's current content and inventory workflow. Some services still need to be connected and checked before the website can launch. This guide does not confirm that the production website or its services are ready.

## Sign in

Open the Payload admin address supplied by your website maintainer and sign in with your staff account. Use your own account. Do not share your password, ask someone to put it in a document, or send it in a support request. If you cannot sign in or need a password reset, contact the website maintainer.

## Add or update a machine

1. In Payload, open **Machines**. Each record represents one physical machine and receives a permanent HGR reference. Do not create a second record for the same machine to change its status or details.
2. Create a record for a new physical machine, or open its existing record to make a correction. Enter only facts HGR has checked. Leave unknown optional facts blank; do not estimate engine hours, year, origin, registration details, or price.
3. Set the stock status separately from whether the record is published. Use **Available**, **Reserved**, or **Sold** to describe stock. A sold machine can remain on the site as a sold record; its URL must not be reused for another machine.
4. Add photographs in the closest matching category. Choose a clear **General / Exterior** image for the featured image. Review previews and image processing messages. Correct factual alt text if needed. Do not put registration cards or ownership documents in the normal photograph gallery.
5. Save as a draft and use the available preview before publishing. Publishing requires the site's required machine facts and a current approved featured image. If validation or photo processing fails, read the displayed message and correct or retry the item. Do not repeatedly create replacement records for an upload error.
6. Copy the machine link using **Copy Machine Link** after the record has a public URL. Share it manually only where HGR permits. If copying is blocked, select the displayed link and copy it from the browser.

## Handle sensitive documents

Keep an original JPJ or ownership document in the separate private document workflow. Never add the private original to a public photo gallery. A public copy must be a separate redacted file, reviewed by a person for names, identification numbers, addresses, serials, QR codes, and other identifying details. Only a staff member with the required permission can publish an approved public copy. If the workflow, permissions, or preview is unavailable, leave the document private and contact the website maintainer.

## Edit ordinary page content

Use **Pages** in Payload for the supporting page content available there. Preview changes before publishing. Keep copy factual and within HGR's approved claims. Do not add unverified addresses, opening hours, service coverage, rental availability, products, prices, reviews, or legal claims.

## When something goes wrong

Read the error on screen and note which record and action were involved. Contact the website maintainer for account lockout, missing permissions, repeated upload or save failures, or service errors. Do not send passwords, customer enquiry details, private document originals, or identification numbers with the report. The admin interface may be available before database, image storage, email, or other deployment services have been connected; a successful local save or preview is not proof those live services are ready.

## Before public launch

HGR must still confirm the real inventory and public copy, approve image/document rights and redactions, complete owner workflow and device checks, and close the deployment gates in [the V1 acceptance record](operations/v1-acceptance.md). Do not publish sensitive material or announce a launch based on this guide alone.
