## Established visual direction

HGR may take inspiration from the polished spacing, premium presentation, controlled motion and modern interaction quality associated with Samsung's digital presentation.

HGR must not copy Samsung's layout, branding, assets or website.

The objective is:

> Visually modern like Samsung, operationally extremely simple.

Samsung is an established conceptual reference. No particular Samsung page URL has been provided or verified for this reference record; URL: [TO CONFIRM]. This note does not claim a current site has been inspected.

## Visual references

Established qualities: generous spacing, strong typography, large real machinery imagery, restrained light/dark contrast and minimal clutter. Apply HGR's own logo, Inter direction and existing colour system.

Specific page examples/screens and usage permissions: [TO CONFIRM]. Do not copy another business's content or assets.

## Interaction references

The planned HGR signature interaction is a stationary excavator body with boom/arm rising naturally on downward scroll, reversing where practical. Exact external reference: [TO CONFIRM].

Evaluate whether any future reference preserves immediate View Excavators and contact access, normal navigation and reduced-motion/static fallbacks. Reject interactions that require visitors to complete an animation before browsing.
