# HGR Asset Requirements

## Purpose and sources

Master asset collection and readiness checklist for V1. This is not evidence that any asset has been received or licensed.

Sources: [[01 - Brand/Brand Guidelines]], [[01 - Brand/Design System]], [[02 - Website Specification/Homepage]], [[02 - Website Specification/Admin System]] and [[03 - Content/Content Requirements]].

[TO CONFIRM] = asset, permission or business detail to obtain. [DEFERRED] = later production/technical choice. [FUTURE] = outside V1. Keep tracking in this note; do not create additional notes or asset folders merely to satisfy this plan.

## Naming and organisation

Use stable, descriptive names, for example [machine-id]-[brand]-[model]-[view]-[sequence]. This is a naming pattern, not actual inventory. Keep machine ID consistent with admin and enquiries. Avoid phone numbers or personal data in public filenames.

Plan separation between originals, edited masters and public derivatives; exact physical storage and organisation are [DEFERRED]. Keep source provenance and version information. Never overwrite an original solely to prepare a website image. Do not duplicate a similar machine's photo set into another listing.

## Processing and public delivery

The owner uploads original high-resolution photographs. The eventual system should handle orientation, resizing, compression, responsive sizes, thumbnails/gallery derivatives and suitable modern formats automatically.

Aim for approximately 200 KB or below per generated image where practical, preserving useful condition detail. This is not an absolute cap on uploads or every gallery derivative. Retain high-quality originals separately where technically appropriate. Serve appropriately sized images rather than originals in cards. Refer to [[05 - Assets/Photography & Video]].

## Watermark requirements

Support No Watermark, HGR Logo, or HGR Logo + hgrmachinery.com on generated public images. Placement, opacity, size and edge margin must be centrally configurable. Bottom-right is the existing proposed default, not a final approved setting.

Keep originals unwatermarked and reusable. Review placement on mobile and detail shots so hours, labels and defects remain visible. Final watermark artwork/default settings [TO CONFIRM]; implementation [DEFERRED]. No storage or CDN vendor has been selected.

## Rights and truthful use

Record permission for photographs, music/video, logo/font/icon files, testimonials and supplier materials. Do not assume online availability permits reuse. Keep licensed manufacturer material tied to the actual product and approved use; it must not imply distributorship.

AI-generated machines must not replace actual listing photographs. Approved marketing production must remain distinct and must not materially change the condition or specification of a machine represented for sale.
