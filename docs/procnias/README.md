# Procnias Product Method

The [Procnias Product Method](PROCNIAS-PRODUCT-METHOD.md) is Procnias' company-wide product methodology. It defines the shared approach that every Procnias product project inherits; it is not specific to HGR.

Each individual project implements the methodology through its own Vision Package. For example, HGR's Vision Package defines the HGR-specific governing principles, philosophy, experience design, engineering expectations, and design guardrails without duplicating the company-wide method.

This methodology is reusable across future Procnias products, including UnkerEats, UnkerHawk, and future Procnias projects. Each product maintains its own project-specific decisions and documents under the shared methodology.
